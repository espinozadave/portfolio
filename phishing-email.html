Phishing Email Investigation & Incident Response Analysis

Overview:

This project simulates a phishing incident investigation within a fictional organization. As a SOC Analyst, I investigated a suspicious email containing a malicious attachment, analyzed indicators of compromise (IOCs) using VirusTotal, documented findings through an incident ticket, applied the Pyramid of Pain framework, and followed a phishing response playbook to guide containment and remediation activities.

Objectives:

  • Investigate a phishing email containing a suspicious attachment.
  • Identify Indicators of Compromise (IOCs).
  • Assess potential business impact.
  • Document findings in an incident ticket.
  • Apply the Pyramid of Pain framework.
  • Follow a phishing incident response playbook.
  • Recommend containment and remediation actions.

Scope:

  • Email header review
  • Attachment analysis
  • IOC identification
  • VirusTotal investigation
  • Incident documentation
  • Response recommendations

Tools & Technologies:

  • VirusTotal

  • Pyramid of Pain
  • Incident Response Playbook

Scenario:

This scenario is based on a fictional company:

I'm a Level 1 Security Operations Center (SOC) Analyst at a financial services company that received an alert indicating that a suspicious file had been downloaded onto an employee's workstation. Initial investigation revealed that the employee had received a phishing email containing a password-protected spreadsheet attachment. The password required to open the file was included within the email message itself.

After downloading and opening the attachment, the employee entered the provided password, which triggered the execution of a malicious payload on the system. The incident generated security alerts indicating potential malicious activity on the endpoint.

As part of the investigation, the suspicious file was collected and analyzed. A SHA256 file hash was generated and submitted to threat intelligence sources to determine whether the file was known to be malicious. Analysis confirmed that the attachment was associated with malicious activity.

Following confirmation of the threat, the incident response process was initiated in accordance with organizational security policies and phishing response procedures. The investigation focused on identifying indicators of compromise (IOCs), assessing the potential impact, documenting findings within the incident ticket, and recommending containment and remediation actions to resolve the incident.

Step 3: Pyramid of Pain Analysis

Indicators of Compromise Identified:

  • SHA256 Hash: VirusTotal identified the attachment as malicious, with 55 of 69 security vendors detecting the file as malware. The file was classified as a Trojan and received a community score of -295, indicating high confidence of malicious activity.
  • Domain:The malware communicated with org.misecure.com through HTTP requests, suggesting outbound communication to attacker-controlled infrastructure.
  • IP Address:DNS resolution linked the domain to 207.148.109.242, an external host potentially used for command-and-control (C2) communications.
  • MD5 Hash:The file's MD5 hash (287d612e29b71c90aa54947313810a25) provides an additional unique identifier for threat detection and investigation.
  • Network Artifacts:Observed DNS lookups and HTTP GET requests indicate the malware attempted to establish external network communications after execution.
  • Command & Control (C2):Communication with the identified domain and IP address suggests the malware was attempting to connect to a remote server for instructions or data exchange.
  • Capabilities:No direct evidence of credential theft or keylogging was observed during analysis; however, the Trojan classification indicates the malware may possess additional capabilities beyond those captured in the sandbox environment.

Figure 8. Pyramid of Pain Mapping of Investigation Findings: Indicators of compromise identified during the investigation were mapped to the Pyramid of Pain framework, including file hashes, IP addresses, domains, network artifacts, and command-and-control activity. This analysis highlights which indicators provide the greatest defensive value and create the highest operational cost for attackers when detected and mitigated.
